# 🐱 CAT DASH — Career Maze Challenge

A classroom 5-player HTML maze chase game.

## How to play
- P1: WASD
- P2: Arrow keys
- P3: IJKL
- P4: TFGH
- P5: 8456
- Each round lasts 20 seconds.
- First player to reach the correct job category gets 2 points.
- Later players who reach the correct answer get 1 point.
- Wrong answers get 0 points.
- Five monsters move around the maze.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and this README.
3. Open Settings → Pages.
4. Select Deploy from a branch.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will provide a public game URL.

Use that URL to create a QR code for students.
